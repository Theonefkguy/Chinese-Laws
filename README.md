# Chinese-Laws

中国现行法律、行政法规、部门规章、地方性法规、司法解释等公开法律文本的整理合集，纯数据，不含抓取/处理代码。

## 目录结构

按法律效力层级分类：

- `宪法` `宪法相关法` —— 宪法及相关法律
- `刑法` `民法典` `民法商法` `经济法` `社会法` `行政法` `生态环境法` `诉讼与非诉讼程序法` `其他` —— 各部门法律
- `行政法规` —— 国务院制定的行政法规
- `监察法规`
- `部门规章` —— 按发布部委分文件夹（公安部、财政部、国家税务总局等）
- `地方法规` —— 按省级行政区分文件夹（`地方法规/<省份>地方法规/`），其中 `待分类` 是尚未确定归属省份的条目
- `司法解释` —— 最高人民法院/最高人民检察院司法解释
- `法律解释`
- `指导案例` —— 最高人民法院指导性案例、最高人民检察院指导性案例

每篇文本为一个 Markdown 文件。法律法规文件名通常为 `<标题>(<公布日期>).md`；指导案例按原案号和标题命名，并保留分类索引。

## 元数据索引

`metadata/document_dates.jsonl` 提供每篇法规文本的结构化日期、效力状态及其文本证据，包括公布、通过、批准、施行、修订、失效等日期。路径均相对于本仓库根目录。

`metadata/curated_repeal_relations.jsonl` 提供人工核验的废止关系，保留废止决定、目标文件、生效或公布日期、证据来源、置信度和核验说明。该索引用于补充正文中没有明确失效日期的历史法规；其中标为 `medium` 的记录应以其证据字段注明的官方登记日期为准。

## db.sqlite3

按上述目录结构生成的索引数据库，供检索类应用直接读取使用。指导案例在数据库中以 `level='指导案例'` 单独标识。

## 数据来源

内容采集自国家法律法规数据库（flk.npc.gov.cn）、各部委官方网站、最高人民法院、最高人民检察院、维基文库等公开渠道，仅供学习研究参考，不构成法律意见；具体条文和案例文本以官方发布为准。

## 更新

本仓库只发布整理完成的文本，不包含采集/处理脚本。
