# 指导案例

这是一个面向阅读和检索的指导性案例文本合集，合并整理最高人民法院指导性案例和最高人民检察院指导性案例。

本目录只发布整理后的 Markdown 案件正文和索引，不包含采集、清洗、解析、入库或导出脚本。

## 阅读方式

从 [_index.md](_index.md) 进入总索引，也可以直接打开各分类目录下的 `_index.md`。

每个案例文件采用 YAML front matter 保存结构化元数据，包括 `case_id`、`file_id`、`issuer`、`category`、`publish_date`、`batch` 和 `keywords`。正文只保留适合阅读的标题、关键词、裁判要点、要旨、相关法条和案例内容，不再显示原始发布日期、批次分隔符等采集痕迹。

网页地址、采集时间、原始页面等出处记录保存在 SQLite 数据库中，不写入阅读用案例 Markdown。

最高法和最高检案号各自独立，例如 `指导案例1号` 与 `检例第1号` 不互相覆盖。
